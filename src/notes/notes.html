Welcome! This is a tool for the virtual pet game Chicken Smoothie, that allows you to find the release date of a pet or item from its image. No longer will you have to wonder you received on December 18th!

Below are the pets currently added to the database:

  • 2008, 2009, 2010 (all pets)

Some pets have multiple in-between "baby" stages. The database is set up to record only one per pet- in the event of multiple stages, the middle-most one is chosen. To see all stages of a pet's growth, please see the linked archive page.

Most pet & litter names are sourced from the Wiki's name guide! Pets without names are assigned descriptive names based on their appearance.
